## Keyra 0.2.1

The Keyra browser extension is now on the Chrome Web Store, so connecting a browser takes one click.

### ✨ New

- **Extension from the Chrome Web Store.** No more Developer mode or "Load unpacked" — install Keyra like any other extension. It works in Chrome, Edge, Brave, Opera and Vivaldi.
- **Open the Chrome Web Store** button in **Settings → Browser**, next to the updated setup steps.

### 🔧 Changed

- The setup steps in **Settings → Browser** now describe the store install instead of the `keyra-extension` folder. Firefox still uses the temporary add-on route.

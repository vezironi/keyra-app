## Keyra 0.2.0

Keyra now keeps itself up to date, and can start with your computer.

### ✨ New

- **Automatic updates.** Keyra checks for new versions when it starts and every 6 hours while it runs.
  - With **Update automatically** on (the default), new versions install as Keyra starts.
  - With it off, you get a notification and the update installs when you click **Update**.
  - Updates are signed and verified before they install.
- **Check for updates** button and the current version in **Settings → Desktop**.
- **Launch at startup.** Keyra can start quietly in the system tray when you sign in, so the browser extension is always connected.

### 🔒 Privacy note

This version sends **anonymous crash reports** (error message and stack trace) to help fix bugs. No vault data, passwords, screen recordings or personal information are included, and console logs and clicks are never recorded. Your vault still never leaves your device.
